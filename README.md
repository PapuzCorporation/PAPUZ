# PAPUZ — веб-клиент

Клиент мессенджера PAPUZ: интерфейс, шифрование личных чатов и работа с медиа.

## Что здесь

- `index.html` — разметка интерфейса
- `app.js` — логика клиента
- `app.css` — стили и темы
- `crypto.js` — сквозное шифрование личных чатов (WebCrypto)
- `media.js` — обработка фото, видео и файлов
- `theme-init.js` — выбор темы до загрузки страницы
- `emoji/`, `fonts/` — локальные ресурсы

## Чего здесь нет

Серверной части, базы данных, ботов и ключей. Сервер PAPUZ получает
шифротекст личных сообщений и метаданные, необходимые для доставки.

## Как запустить

Это статический клиент, но ему нужен API PAPUZ. Без сервера откроется
только интерфейс.

```sh
python3 -m http.server 8080
```

Затем открой `http://localhost:8080`.
